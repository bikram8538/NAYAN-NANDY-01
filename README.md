# NAYAN NANDY — GitHub Pages website

This is the static website for **NAYAN NANDY — Global Agri Trade**, prepared for GitHub Pages. It includes the original product photos, optimized product video, CSS, JavaScript, and the Ruby Palace office address.

## Deploy on GitHub Pages

1. Sign in to [GitHub](https://github.com/), create a **Public** repository named `nayan-nandy-website`, and choose **Create repository**.
2. Extract the ZIP file. Upload **the contents** of the extracted folder (including `index.html`, `styles.css`, `app.js`, and the complete `assets` folder) to the repository root. Do not upload just the ZIP file or put the entire extracted folder inside an additional folder.
3. Commit the uploaded files to the `main` branch.
4. Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then click **Save**.
5. Wait for deployment, then open `https://YOUR-GITHUB-USERNAME.github.io/nayan-nandy-website/` (replace the username).

The site uses relative local asset paths, so it works both at a GitHub project subpath and at the root of a custom domain.
